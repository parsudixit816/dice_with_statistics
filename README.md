# Dice Emulator with 2 Players and Statistics

A simple dice emulator with statistics.

### Features

* Shows how often each number (1–6) was rolled.
* Shows the percentage for each number.
* Has 2 modes:

  * **1. Single Player**
  * **2. Two Players**
* In 2-player mode, it automatically switches between players.
* You can choose how many times you want to roll the dice by entering a number.
* Press **Enter** to roll once.
* Enter **q** to quit.
* Calculates separate statistics and percentages for both players.
* Different rolling behavior for the 2-player mode.

### Platform

* Linux only for now.
